# 恋愛シミュレーション 軽量版

[軽量版を開く](https://namiyukuta-cmd.github.io/renaigame/simulation-lite/)

1. 通常版で設定したGitHubトークンで接続し、非公開セーブを開きます。新規の場合は主人公と相手を設定して「新しい物語を非公開で保存して始める」を押します。
2. 「AIにコピーして渡す」を押し、ChatGPTへ貼り付けます。空欄でも設定と現在の記録を引き継げます。主人公の台詞・行動は画面に書いて一緒に渡すことも、ChatGPTで直接入力することもできます。
3. ChatGPTに **「保存して」** と伝えます。AIが接続済みGitHubから非公開セーブを更新し、再取得して確認します。JSONの貼り付けや画面の保存ボタンは通常不要です。

手動取り込みを使う場合は、最初に「JSONファイルを選択」が表示されます。貼り付ける場合だけ「または章JSONを貼り付ける」を開いてください。

保存先は **namiyukuta-cmd/private-game-data**。正本は通常版と同じ `renaigame/simulation/saves/<saveId>.json` です。本文・主人公設定・心理状態を公開リポジトリへ保存しません。AIはChatGPTの接続済みGitHubを使います。画面のロードには通常版で設定したトークンを共用し、それをAIへ渡す必要はありません。端末には共通のキャッシュと入力の下書きが残りますが、保存完了は非公開GitHubへの反映と再取得を確認してから案内します。

画面下の「AIに渡す」「記録」「プロフィール」「セーブ」で表示を切り替えます。「メニュー」から接続・新規作成・ロードができます。画面を切り替えても入力の下書きは残ります。人物画像を読み込みません。初期表示では小さな相手目録を読み、検証時は選択中の人物のJSだけを同一コミットから取得します。AIへは本文全文・現在心理全項目を渡し、過去の計算履歴は参照に短縮します。完全な計算履歴は非公開正本に残ります。生成のためだけにAIが巨大なセーブを再取得する手順を省きます。

共通の心理JS・意味確認・本文検証、標準version 2の章形式を使います。保存のたびにスロットを選び直したり、保存ボタンを押したりする必要はありません。違う物語の章、同一章の異なる内容、章飛ばし、競合は上書きしません。AIが保存した内容はゲームへ戻った時に自動で読み込みます。「AIが保存した物語を読み込む」からの再読み込みもできます。手動のJSON取り込みは折りたたみ欄に残しています。AI自体の出力時間が一定になる保証はありません。

AIの生成資料は`RenaiGameTurnRuntime.liteRulePaths`で選びます。選択中の人物の開始メモを使い、通常版の入口全文・他人物の設定・保存専用資料を本文生成のたびに追加取得しません。毎Turnの最新HEAD確認後、同じcommitの取得済み原文は実行器・規則も再利用し、変更・欠落時に取得します。別の会話へキャッシュが自動で渡るとは扱いません。計測条件と取得数・バイト数は[読み込み計測](LOAD_BENCHMARK.md)に記録しています。

AI向け入口は [AI_ENTRY.md](AI_ENTRY.md)、保存依頼時の実行手順は [AI_SAVE.md](AI_SAVE.md)。相手目録は`node simulation/scripts/generate_lite_catalog.cjs`、人物別の開始メモは`node simulation/scripts/generate_lite_ai_notes.cjs`で正本から生成します。資料を変更したら`node simulation/scripts/benchmark_lite_loading.cjs --write`で計測表を更新します。
