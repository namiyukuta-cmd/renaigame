# Chapter 8

キャンディーを舐め終えた後、忍はエリオットに「キャンディーカード、いる？」と尋ねた。しかし返事を待たずに書き始め、カードを専用の封筒へ入れて封をし、「はい」とエリオットへ渡した。

その仕草は、エリオットがカードを欲しがることをすでに分かっているようなものだった。

忍は「またね」と、次回来店を疑わないように告げた。その直後、悪戯を仕掛けるような顔で「…いつまでいるか、分からないけど」と付け加えた。

エリオットはその一言で、それまでの羞恥より先に表情を止めた。「何ですか、それ」「どういう意味ですか」「店を辞めるとか、そういう話ですか」と、からかいとして流さず意味を確認しようとした。

さらに「あなた、さっき僕に聞きましたよね」と、忍が先ほど自分へ「いつまで？」と問うたことを持ち出し、「それで僕には答えさせておいて、自分はそれですか」と不満を示した。

そして「次に来たとき、いなくなっていたら、困ります」「かなり」と、忍が店からいなくなることを嫌がる気持ちを本人へ直接伝えた。退店時には「……また来ますから」と、以前より強く再来店を明言した。

店を出た後、エリオットは二枚目のキャンディーカードを開封した。

カードには『今日のキャンディーは長細くて喉の奥まで甘味でいっぱい。溺れそう。Shinobu』と書かれていた。

エリオットは文面を何度も読み返し、強く動揺した。ただし文章はキャンディーについてのものだと理解し、忍の恋愛的・性的意図まで決めつけてはいない。

二枚目のカードも前のカードと同じく持ち帰った。しかし今回、最も強く頭に残ったのはカードの文章よりも、忍の「いつまでいるか、分からないけど」という言葉だった。

エリオットは、次に店へ来たとき、その理由を必ず忍へ聞こうと決めた。

## この章で確定した進展

- 忍はエリオットの返事を待たず、二枚目のキャンディーカードを書いて渡した。
- 忍はエリオットがカードを欲しがることを分かっているような態度を見せた。
- 忍は「またね」と、エリオットが再来店することを疑わないように告げた。
- 忍は「いつまでいるか、分からないけど」と発言した。理由・意味はまだ未確定。
- エリオットはその言葉を流さず、「どういう意味ですか」「店を辞めるとか、そういう話ですか」と確認した。
- エリオットは「次に来たときいなくなっていたら、困ります。かなり」と、忍がいなくなることを嫌がる気持ちを本人へ伝えた。
- エリオットは「また来ますから」と再来店を明言した。
- 二枚目のカードには『今日のキャンディーは長細くて喉の奥まで甘味でいっぱい。溺れそう。Shinobu』と書かれていた。
- エリオットは二枚目のカードも持ち帰った。
- エリオットは次回来店時、忍が「いつまでいるか分からない」と言った理由を必ず確認するつもりでいる。
- 忍の恋愛感情、カード文面の恋愛的・性的意図、「いつまでいるか分からない」の理由は未確定。
- 店外連絡、在留相談、エリオットの職業発覚はまだ起きていない。
