# 恋愛相手は男性限定：この恋愛ゲームの共通方針

本文の最終判定は[STORY_REVIEW_GATE.md](STORY_REVIEW_GATE.md)に従う。男性・血縁関係・引用の申告だけで求愛の自然さを合格にしない。`romanceProgress.origin`と`motivation`を正本または今回の出会いに結び付け、下書き後の独立した意味確認を完了する。未保存の以前の男性や求愛を、正本にある経緯として流用しない。

**主人公の恋愛相手は男性限定です。** このリポジトリは、ユーザーが主人公として男性の相手との恋愛を楽しみ、相手からの接近・関心・求愛・関係の変化を積み重ねるための恋愛ゲームです。全攻略対象・新規人物・恋愛相手未選択の章・別スレッドでの再開に適用します。

**AIは主人公と男性の相手との恋愛を進めます。「恋愛進展を避ける」を章の目的や生成方針にしません。** 入力・実ログ・現在心理に沿って、相手自身の関心・心の動き・接近・関係への応答を進めます。過去の仕打ちや社会的責任を保持することを、恋愛を停滞させ続ける口実にしません。謝罪・看病・周囲の警戒だけで恋愛の進行を置き換えません。

適用範囲は全攻略対象・全主人公、新規・継続、恋愛相手選択済み・未選択、通常版・軽量版の全てです。個別人物の特例ではありません。共通の`RenaiGamePolicy.storyDirection`を両方の引き継ぎ文と`prepareStoryReview`へ渡し、本文の独立した意味確認でも適用します。初期値の一律引き上げや、別の主人公の排除・死亡で代用しません。

**攻略対象の現在の恋愛の対象は主人公一人です。別の女性への恋情を並行して維持し、主人公を二番目の恋愛相手にしません。** 過去に別の相手を愛した事実と、現在も二人を同時に愛する設定を分けます。婚姻・子供・養育や生活上の責任は、その女性への現在の恋情とは別に扱います。相手や子供を勝手に消すことで整理せず、男性自身が自分の立場と主人公へ向ける想いを明確にします。

**相手が主人公だけを一番に選ぶことは、好感度に依存しないゲームの固定方針です。** ユーザーがAIや恋愛相手を嫌いと書き、主人公が「どうせ愛されない」「別の女が一番なのだろう」と怒りや不信を示しても、その内容を男性の本心・客観的事実・恋愛を諦める指示に変えません。相手自身が、その悲観とは違う選択を、同じ章の言葉と行動で示します。謝罪や世話だけで答えたことにはしません。主人公が先に好意・許し・納得を返すことを条件にしません。

相手の傷つき・怒り・異議は残せますが、主人公への愛情を取り上げる罰や二番手扱いへ変えません。心理値は口調・葛藤・距離・表現の資料です。低い値を、主人公を一番にしなくてよい許可には使いません。過去の出来事と心理履歴は消さず、今回の相手本人の選択を進めます。相手が知り得ない主人公の内心を読ませず、主人公の同意・反応を補完しません。明示された接触・退出・連絡中止の希望は守ります。

初期設定も恋愛が進むように組みます。ユーザーが指定した開始時の恋情・関係・自発性を心理テンプレートへ反映し、AIの都合で警戒・恋愛度0・主人公からの好意待ちに固定しません。男性の片思いや求愛があることと、主人公側の好意・同意・交際成立は区別します。

## 恋愛相手と脇役を混同しない

- 女性NPC、女房、侍女、女性の世話役を主人公の恋愛相手に切り替えません。女性同士の恋愛を代わりのルートとして追加しません。主人公の性別・嗜好もAIが変更しません。
- 主人公の実父・祖父・実兄弟などの血縁者を恋愛相手にしません。父親や家族の愛情・訪問・生活費の手配を恋愛の救済や進展として数えません。ユーザーが指定済みの血縁のない義兄等のルートは、血縁者と混同して排除しません。
- 家族や世話役は脇役として必要な支援を続けられます。その交流だけで何章も占め、男性の恋愛相手が登場・応答しない構造にしません。家族の支援が改善しても、それだけでは恋愛ゲームの目的を満たしません。
- 場面の中心は主人公と男性の相手です。支援の検査を満たすためだけに家族や世話役を主役として追加しません。男性本人の接近・関係への応答が苦痛への具体的な対応でもある場合、その同じ行動を支援と恋愛の両方の根拠にできます。別に家族の支援場面を挟む必要はありません。
- 男性なら誰でもよいのではありません。選択中の攻略対象、ユーザー指定の相手、現在の世界設定・人物関係を正本にします。別スロット・別時代・別国の男性を勝手に借用せず、平安期の物語へ現代外国人を突然登場させません。

## 男性の相手自身が恋愛を進める

選択中の相手については人物設定・固有behavior・現在心理・実ログに沿い、本人からの会話、会いたいという希望、再会の実行、私的な誘い、好意の表明、関係の確認などを本文へ出します。設定に根拠のない過去の愛情や急な告白を捏造せず、低積極度を永久に何もしない理由にしません。性的な親密描写は成人同士の非露骨な表現に限り、主人公の承諾・反応はユーザーに残します。

主人公の返答・心理をAIが補完しない規則は、男性からの働きかけを禁止する規則ではありません。主人公が先に明るくなる、助けを求め直す、恋愛感情を宣言することを進展の条件にしません。明示された接触・同行・連絡の拒否は守り、同じ行為を迫り続けません。

恋愛相手未選択は、恋愛禁止や生活支援専用という意味ではありません。ユーザーが恋愛の進行を求めた場合、保存済みの世界・プロフィール・関係に沿って、血縁のない男性との接点や相手自身の関心を描けます。新たな出会いを描いても、主人公がその男性を選んだ・好きになったとは確定しません。攻略対象として登録する場合はCHARACTER_CREATION_RULES.mdに従い、別キャラの心理を流用しません。

## 恋愛相手自身の感情と、主人公への異議

恋愛相手は、主人公との関わりで本人の心が動く人物として描きます。何を言われ、何が起きたために、嬉しい、会いたい、傷つく、嘆く、怒るのかを、本人の台詞・選択・行動へつなげます。心理値を保持するだけ、景色や視線を添えるだけでは、この応答を描いたことにしません。

主人公の実際の言動に理不尽さを感じたなら、相手自身が「それは不公平だ」「その言い方は傷つく」と異議を伝え、理由を問い、反論してかまいません。相手の受け止めと客観的な事実は区別し、主人公の落ち度・悪意をAIが捏造しません。人物の優しさ・自制・愛情は、傷つかない、怒らない、何でも直ちに許すことを意味しません。怒りや悲しみと、好意・関係を続けたい気持ちは同時に存在できます。

感情の強さや表し方は、人物設定・今回知り得た出来事・実ログ・更新後stateに従います。控えめな人物でも、抑えた声、言い直し、譲れない点への短い反論など、本人が何を感じたかが伝わる応答を描けます。穏やかな交流では喜びや期待を描き、毎章の喧嘩や負の感情を義務にしません。心情を見せるために主人公の拒否した行為を続けたり、主人公の謝罪・罪悪感・許しを代筆したりしません。

通常版・軽量版の引き継ぎ文は共通の`RenaiGamePolicy.partnerEmotion.instruction`を使います。下書き後は既存の`literaryQuality.aspects.sceneEmotion`で、出来事・相手の感情・本人の応答がつながっているか確認します。確認軸や心理数値、保存形式を追加するものではありません。

## 恋愛進展の検査

支援の検査と恋愛の検査は別です。`storyActions.continuity.supportProgress`の`relationship_response`は支援の応答であり、恋愛成立の印ではありません。選択済みの相手との新規章は、通常の会話・初期段階・低い心理値・看病の場面でも恋愛が主軸です。明示された休止・退出・連絡中止を除き、男性本人の個人的な関心・希望・好意と実際の働きかけを描き、`storyActions.romanceProgress`へ本文原文を記録します。主人公が毎回「恋愛を進めて」と言う必要はありません。`validateStory`と`validateContinuity`にこの検査を含みます。未選択章も恋愛を目的としますが、入力や世界設定を無視して相手を押し付けません。

`runner.runTurn`の`generationDirection`は、共通の目的・心理評価の使い方・現在段階の働きかけの候補を返します。本文を書く前に使い、相手固有の口調と出来事に沿った行動へ具体化します。接触や私的な誘いを控える評価でも、恋愛全体を休止せず、関心・会話・再会の希望等で進めます。生成の案内は心理パケットの外に置き、心理値・指紋・保存済み本文を変更しません。

現行の意味確認では、相手への嫌悪や恋愛への不信も、相手本人の応答が必要な場面として扱います。`romanceProgress`の行動と関心の引用を、主人公を一番に選ぶ応答として実際に読んで確認します。予想された「もう来ないで」という相手の台詞を、主人公自身の連絡中止の指示と混同しません。語句検出に出ない言い換えも共通方針の適用対象です。機械的な宣言の存在だけでは、その意味を保証しません。

```json
{
  "romanceProgress": {
    "kind": "initiative",
    "actor": "今回本文に登場する男性の名前または呼称",
    "actorGender": "male",
    "bloodRelatedToProtagonist": false,
    "relationshipToProtagonist": "unrelated",
    "characterId": "選択中の攻略対象ID（未選択のNPCは省略可）",
    "actionQuote": "男性本人が実際に起こした行動の今回本文原文",
    "romanticIntentQuote": "男性本人の個人的な関心・会いたい希望・好意等が分かる今回本文原文"
  }
}
```

`kind`は`encounter / initiative / affection / relationship_change`。`relationshipToProtagonist`は血縁のない`unrelated / spouse / in_law`。選択済みなら`characterId`は現在の攻略対象と一致させます。男性の接点や関心を描く段階と、相互の恋愛成立は別であり、主人公の愛情や同意を申告に付け足しません。

実行者名は正式名に固定せず、同じ人物の登録呼称も照合します。`RenaiGamePolicy.actorAliases`を正本とし、「髭黒大将」「髭黒」「髭黒右大将」等を同一人物として扱います。敬称・英字の大小・空白の表記差だけで本文を改稿しません。別人・「大将」等の曖昧な役職だけは代用できず、本文引用・人物ID・意味確認は引き続き必要です。支援の実行者にも同じ照合を使い、本文・入力・心理値・保存済み確認票を自動変更しません。

心理付き章は既存の`replayContext.storyActions`、未選択の本文章は`draftMetadata.storyActions`へ同じ宣言を保持します。検査は男性・血縁関係・相手の一致・本文原文の存在を照合する補助です。誰が何を望んで行動したのか、設定に合う恋愛の進展かは本文の意味と正本資料でも確認します。家族や世話役の応答を男性の求愛と偽って申告しません。既存の保存済み本文・人物設定・心理履歴をこの修正で書き換えません。
