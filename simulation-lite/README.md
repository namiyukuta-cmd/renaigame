# 恋愛シミュレーション 軽量版

[軽量版を開く](https://namiyukuta-cmd.github.io/renaigame/simulation-lite/)

1. 主人公と男性の相手を設定し、「この設定で始める」を押します。
2. 主人公の台詞・行動を入力し、「AIに渡す文章をコピー」からChatGPTへ貼り付けます。
3. 保存するときはChatGPTに「保存JSON」と伝えます。返されたJSONを「受け取った章を保存」へ貼り付けます。
4. 「章を確認する」で心理計算と本文検査を再実行し、表示された本文を確認して「この章を端末に保存」を押します。

GitHubトークンは不要です。物語と下書きは、この端末のブラウザに保存します。別の端末へ移すときやブラウザの保存データを消す前は「全物語をJSONに書き出す」でバックアップしてください。通常版の既存セーブとは別の保存領域を使います。

画面は1ページ、人物画像は読み込みません。相手一覧は名前等の小さな目録だけを読みます。人物JS・行動JS・心理JS・検査JSは章の確認時に選択中の相手の分だけ取得します。AIへは本文全文と現在心理を渡し、過去の計算履歴は参照だけにして転送量を減らします。完全な履歴は端末とバックアップに残します。心理項目や本文の確認を省略するモードではありません。AIの生成時間が一定になる保証はありません。

AI向けの入口は[AI_ENTRY.md](AI_ENTRY.md)。章JSONの形式は共通の標準version 2であり、端末のバックアップJSONとは異なります。既存の本文・心理履歴を上書きせず、同じ章の同じ内容は二重追加しません。

人物目録は`node simulation/scripts/generate_lite_catalog.cjs`で生成します。人物の正本は既存の人物JSです。
