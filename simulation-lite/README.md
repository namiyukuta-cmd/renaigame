# 恋愛シミュレーション 軽量版

[軽量版を開く](https://namiyukuta-cmd.github.io/renaigame/simulation-lite/)

1. 通常版で設定したGitHubトークンで接続し、非公開セーブを開きます。新規の場合は主人公と相手を設定して「新しい物語を非公開で保存して始める」を押します。
2. 主人公の台詞・行動を書き、「AIに渡す文章をコピー」からChatGPTへ貼り付けて遊びます。
3. ChatGPTに **「保存して」** と伝えます。AIが接続済みGitHubから非公開セーブを更新し、再取得して確認します。JSONの貼り付けや画面の保存ボタンは通常不要です。

保存先は **namiyukuta-cmd/private-game-data**。正本は通常版と同じ `renaigame/simulation/saves/<saveId>.json` です。本文・主人公設定・心理状態を公開リポジトリへ保存しません。AIはChatGPTの接続済みGitHubを使います。画面のロードには通常版で設定したトークンを共用し、それをAIへ渡す必要はありません。端末には共通のキャッシュと入力の下書きが残りますが、保存完了は非公開GitHubへの反映と再取得を確認してから案内します。

画面は1ページで、人物画像を読み込みません。初期表示では小さな相手目録を読み、検証時は選択中の人物のJSだけを同一コミットから取得します。AIへは本文全文・現在心理全項目を渡し、過去の計算履歴は参照に短縮します。完全な計算履歴は非公開正本に残ります。生成のためだけにAIが巨大なセーブを再取得する手順を省きます。

共通の心理JS・意味確認・本文検証、標準version 2の章形式を使います。保存のたびにスロットを選び直したり、保存ボタンを押したりする必要はありません。違う物語の章、同一章の異なる内容、章飛ばし、競合は上書きしません。AIが保存した内容はゲームへ戻った時に自動で読み込みます。「AIが保存した物語を読み込む」からの再読み込みもできます。手動のJSON取り込みは折りたたみ欄に残しています。AI自体の出力時間が一定になる保証はありません。

AI向け入口は [AI_ENTRY.md](AI_ENTRY.md)、直接保存の実行手順は [AI_SAVE.md](AI_SAVE.md)。相手目録は人物JSを正本として `node simulation/scripts/generate_lite_catalog.cjs` で生成します。
